# MiniRedis

A Redis-inspired in-memory key-value store built using Java.

## Current Features

- SET key-value pairs
- GET values
- DELETE keys
- Check if a key exists
- Basic command parsing
- Command handling

## Technologies

- Java
- Java Collections
- HashMap
